# Street Driver

A browser-based real-world driving and exploration game powered by Google Street View.

## MVP
- React + TypeScript + Vite
- Google Maps JavaScript API
- Street View panorama viewer
- Car/bike mode
- Keyboard driving controls
- Speed, heading and distance HUD

## Setup
1. Install Node.js 20+.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Add your Google Maps API key as `VITE_GOOGLE_MAPS_API_KEY`.
5. Run `npm run dev`.
